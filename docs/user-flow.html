Daily Shorts Uploader: user flow

The only user is the channel owner. Setup happens once; after that the job runs unattended.

  1. One-time setup (owner): signs in with Google, picks their own channel, and grants youtube.upload and youtube.readonly on the OAuth consent screen. The refresh token is stored as an encrypted secret.
  2. Every day: the scheduler starts the job, which renders the day's episode (owner's original content).
  3. Upload: the job exchanges the refresh token for an access token and calls videos.insert with title, description, made-for-kids = false and synthetic-media disclosure; privacy = public.
  4. Confirm: channels.list (mine=true) checks the destination is the owner's channel; the new video ID is written to a private log.
  5. Revoke any time: the owner removes access at myaccount.google.com/permissions; uploads stop immediately.
