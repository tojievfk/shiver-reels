Daily Shorts Uploader

YouTube  This tool uses YouTube API Services.

A small private tool that publishes the owner's own original short videos, one per day, to the owner's own YouTube channel, Instagram account and Facebook Page. It runs as a scheduled server-side job. It has no other users and does not access anyone else's channel or data.

What it does with YouTube

  • Uploads one Short per day to the owner's channel (videos.insert), with title, description and the synthetic-media disclosure.
  • Reads the owner's channel name to confirm the destination (channels.list, mine=true).

Access can be revoked at any time at Google security settings. By using YouTube features you agree to the YouTube Terms of Service.
